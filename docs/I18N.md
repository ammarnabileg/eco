# Languages (storefront)

The store is Arabic-first (RTL) with English (LTR), and is built so more languages can be added.

## Addresses

| Language | Address |
|---|---|
| Arabic (default) | `/kw/products/...` — unchanged |
| English | `/kw/en/products/...` |
| Any new language | `/kw/<code>/...` |

`src/middleware.ts` handles the language segment:
- It strips the language from the address, serves the same route, and passes the language in the `x-laly-locale`
  request header.
- `/kw/ar/...` redirects to the address without the language.
- The last language is also kept in the `_laly_locale` cookie, for routes without a language in their address (payment
  returns).

## Code

| Need | Use |
|---|---|
| Text in a server component or page | `const t = await getT()` from `@i18n/server`, then `t("cart.title")` |
| Text in a client component | `const t = useT()` from `@i18n/client` |
| The current language | `await getLocale()` (server) or `useLocale()` (client) |
| Links | `LocalizedClientLink` (adds `/kw` and `/en` itself) |
| Server redirects | `redirect(await localizedPath(countryCode, "/account"))` from `@i18n/server` |
| Prices | `convertToLocale({ ..., locale: intlLocale(locale) })`, `getProductPrice({ product, locale: intlLocale(locale) })` |
| Dates and numbers | `toLocaleDateString(intlLocale(locale), ...)` |
| Bilingual rows from the backend (`title_ar`, `title_en`) | `localize(row, "title", locale)` falls back to English, then Arabic |
| Page metadata | `generateMetadata` with `getT()`, not a constant `metadata` object |

Placeholders: `t("cart.items", { count: 3 })` with `"items": "{count} منتجات"`.

## Messages

`src/i18n/messages/<lang>/<namespace>.json`, one file per area: layout, home, catalog, pages, product, cart, checkout,
order, account.
- Keys are `snake_case` inside a namespace, and code uses `"namespace.key"`.
- Every language has the same files.
- A key missing in a language falls back to English, then Arabic. If it's missing everywhere, the key itself shows, so
  gaps are visible.

## Rules

- Translate meaning, not word by word. English is natural shop English.
- Never add promises in a translation. Warranty, returns, delivery and prices say exactly what the Arabic says.
- Brand names, product names and model numbers are not translated.
- Layout must work both ways. Use logical classes (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`, `text-start`),
  never `ml-`, `mr-`, `left-`, `right-` or `text-left`. Arrows that point "forward" use `rtl:-scale-x-100`.

## Adding a language (for example French)

1. `src/i18n/config.ts`: add `fr` to `LOCALES` (label, direction, Intl locale).
2. Copy `src/i18n/messages/en` to `messages/fr`, translate the files, and register them in `messages/index.ts`.
3. Catalogue content in that language comes from the backend's translations. Until it is entered, English is shown,
   then Arabic.
